Common questions

  • My run's distance looks off. Allow precise location for Ultra in iOS Settings → Ultra → Location, and wait for "GPS ready" before you start.
  • The run stopped when I locked my phone. Set Ultra's location access to "Always" or "While Using" with precise location on, and don't force-quit the app during a run.
  • How do I bring in old runs? You → Settings → Import runs brings in runs from Apple Health, including ones from an Apple Watch.
  • How do I turn off run reminders? You → Settings → Morning reminder on run days.
  • How do I delete my account? You → Settings → Delete account. This deletes your profile and every run from our servers.
